# TechSkill — Online IT Courses Catalog

Веб-застосунок каталогу онлайн-курсів (Варіант №5), реалізований у межах курсу «Веб-технології та веб-дизайн».

## Функціонал сторінок
- **Home (`index.html`)** — головний банер, огляд освітніх напрямів та популярні курси.
- **Courses (`courses.html`)** — повний каталог курсів із панеллю фільтрів за категоріями та рівнем складності, а також пошуком.
- **Course Details (`course-details.html`)** — детальна інформація про курс, результати навчання, інтерактивна програма курсу (`<details>/<summary>`) та блок вартості.
- **Enrollment (`enrollment.html`)** — форма реєстрації та оплати з підсумком замовлення.

## Архітектура стилів (SCSS 7-1 + БЕМ)
Усі стилі організовано за методологією **БЕМ** та патерном **7-1** у директорії `src/styles/`:
- `abstracts/` — дизайн-токени кольорів, шрифтів і брейкпоінтів (`_variables.scss`), кастомні функції `rem()` та `color-mix-tone()` (`_functions.scss`), міксини для флексу, гріда, контейнера, типографіки та 12-колонкової сітки з gutters (`_mixins.scss`).
- `vendors/` — нормалізація базових стилів браузерів (`_normalize.scss`).
- `base/` — скидання відступів (`_reset.scss`), адаптивна типографіка (`_typography.scss`), система анімацій `appear`, `fade`, `slide` (`_animations.scss`), utility-класи (`_utilities.scss`) та правила для друку (`_print.scss`).
- `layout/` — 12-колонкова сітка та контейнер (`_grid.scss`), шапка (`_header.scss`) і підвал (`_footer.scss`).
- `components/` — кнопки (`_buttons.scss`), бейджі (`_badges.scss`), картки (`_cards.scss`) та елементи форм (`_forms.scss`).
- `pages/` — адаптивні сітки та специфічні стилі для кожної з 4 сторінок під брейкпоінти `360px`, `768px` та `1280px`.
- `themes/` — налаштування темної теми та CSS-змінних (`_dark.scss`).

## Запуск та збірка
- `npm run dev:vite` — запуск локального сервера розробки.
- `npm run build` — збірка проєкту в папку `dist/`.
- `npm run deploy` — публікація зібраної версії на GitHub Pages.
